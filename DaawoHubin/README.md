# DaawoHubin

**DaawoHubin** waa mashruuc frontend ah oo lagu maamulo xogta dawooyinka, lagula socdo taariikhda dhicitaanka, laguna sameeyo hubin hordhac ah oo ku saabsan batch number-ka.

## Teknoolojiyada
- HTML5 – qaab-dhismeedka bogagga
- CSS3 – naqshadda responsive-ka
- JavaScript – shaqada system-ka iyo kaydinta xogta
- localStorage – xogta waxay ku kaydsan tahay browser-ka qalabkaaga

## Sida VS Code loogu furo
1. Soo saar (Extract) ZIP-ka.
2. Fur Visual Studio Code.
3. Dooro **File → Open Folder**.
4. Dooro folder-ka `DaawoHubin`.
5. Fur `index.html`, kadib isticmaal **Live Server** (Right click → Open with Live Server). Haddii aadan haysan Live Server, ku rakib extension-ka magacaas leh ama si toos ah browser-ka ugu fur `index.html`.

## Waxyaabaha uu qabanayo
- Dashboard leh tirada guud, kuwa la xaqiijiyey, dhacay iyo kuwa laga shakisan yahay.
- Ku dar, wax ka beddel, tirtir, raadi oo kala shaandhee dawooyinka.
- Hubin hordhac ah oo ku salaysan batch number iyo xogta demo-ga.
- Digniino dawooyinka dhacay iyo kuwa 30 maalmood gudahood dhacaya.
- Warbixin iyo CSV export.
- Responsive design oo ku shaqaynaya desktop iyo mobile.

## Muhiim: xadka demo-ga
Mashruucani waa **prototype waxbarasho**. Ma laha server ama xiriir toos ah oo la leh wasaaradda caafimaadka, hay'ad dawooyin, soo-saare, ama database caalami ah. Sidaas darteed:
- “La xaqiijiyey” waxay ka dhigan tahay in xogtu ku jirto diiwaanka demo-ga oo keliya.
- “Lama helin” macnaheedu ma aha in daawadu been-abuur tahay.
- Sawirradu waa sawirro tusaale ah oo internetka laga soo bandhigo; waxay u baahan karaan internet.
- Ha u adeegsan go'aan caafimaad ama iib/isticmaal dawo oo dhab ah adigoon helin xaqiijin rasmi ah.

## Horumarin mustaqbalka
Si loogu beddelo nidaam dhab ah oo farmashiyeyaashu wadaagaan, ku dar backend (tusaale Node.js + Express), database (PostgreSQL/MySQL), login iyo roles, audit logs, barcode/QR scanner, iyo API rasmi ah oo hay'adda sharciyeysan bixiso.
